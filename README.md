# IEEE CEME website assets

Styles, scripts, and images for the IEEE Student Branch, NUST CEME website (edu.ieee.org/pk-ceme).
WordPress loads them through jsDelivr, so the WPCode snippets on the site stay small.

- `ieee.css` shared styles for every page
- `ieee.js` menu, events from The Events Calendar, office bearer badges, forms
- `hero.js` the power core on the home page (uses three.js)
- `campus.jpg` campus photo

To publish a change: commit, create a new tag (v1.0.1 and so on), and update the version number in the snippets.
